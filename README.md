# Manager-de-dieta
Aplicația ajută utilizatorul să țină evidența alimentelor consumate zilnic și să urmărească aportul de calorii și proteine.

1-Utilizatorul poate adăuga un aliment și cantitatea consumată.
2-Aplicația calculează caloriile și proteinele pentru alimentul introdus.
3-Aplicația afișează totalul de calorii și proteine pentru ziua respectivă.
